Eagle Advanced Downloader

Get started

  1. Install the extension from your browser's official store and open Eagle.
  2. Open a fresh media detail page, choose Pick a position on this page and save an active domain preset.
  3. Turn Automatic imports ON, reload the source gallery, then middle-click a link to that media page.
  4. Wait for the import. Use Close imported tabs only when you want confirmed background tabs closed.

Troubleshooting

Check Eagle connection, the ON switch, an active matching preset and the saved position. Website access must be permitted. Reload galleries after an extension update. If the website shows a challenge, open that tab and follow its instructions.

For support, state browser/version, extension version, page URL and expected result. If you choose to share diagnostics, review them first and remove private addresses, signed tokens and artwork names you do not want to disclose. There is no automatic diagnostic upload.

Images, GIFs and some direct video files are supported; protected/streaming players and every possible layout are not. Tested platform: Windows; Eagle 3.0.0 Build45. Firefox requires version 140 or newer.
