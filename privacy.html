Privacy & support

What stays on your computer

Eagle Advanced Downloader has no publisher-operated backend, analytics, advertising, account system or automatic diagnostic uploads. Automatic imports are OFF by default. An active destination-domain preset is required for an import.

While enabled, the extension observes middle-click gestures and matching tab navigation. It inspects media at your saved position, including URLs, page titles, image descriptions, dimensions and loading state. It does not read form fields or record typed text.

Presets and the ON/OFF setting are stored in this browser profile. Pending imports, source and media addresses, tab identifiers and up to 300 diagnostic events are kept in browser session storage. These can include private or signed URLs. Preset backups contain domains, positions and timing settings; they do not contain import history or tab state.

What is transferred

The extension sends the selected media URL, its title and the source-page URL to your locally running Eagle application at http://localhost:41595. These transfers leave the browser but are directed to the same computer. The source-page URL is saved with the imported item in Eagle. No page content is sent to the extension publisher.

Media-size checks can request the selected image from its website or CDN using the page's normal browser environment, which may use that site's existing cookies. Eagle then requests the media file from its host. Those services receive normal request information such as your IP address and the requested address. The extension does not collect cookie values or passwords for transmission to the publisher. The website's, host's and Eagle's own privacy practices apply separately.

Your controls

Turn Automatic imports OFF to stop observing new import gestures and cancel waiting jobs. Requests already sent to Eagle may finish. Remove or disable a preset to stop imports for that domain. Batch closing only happens when you press Close imported tabs; active, pinned or subsequently navigated tabs stay open.

Presets can be deleted in Presets & delay. Session records are temporary and are not a cloud backup. Removing the extension removes its browser-managed data; exported JSON files, media and metadata already saved in Eagle remain until you delete them separately.

Copy diagnostics only when you want to share them. Review the text first: it can reveal domains, artwork titles and media addresses. Copying writes to your clipboard; it does not automatically contact support.

Requirements & support

Install and open the Eagle desktop application, allow the local API connection, enable Automatic imports and save a destination preset. Reload an already open source gallery after installing or updating the extension. For support, use the publisher contact on your extension's store listing.

Direct images, GIFs and some direct HTTP(S) video files are supported. Protected players, blob URLs, HLS/DASH streams, browser-protected pages and embedded frames are not supported. Website security challenges must be handled on the website.
